# Taskflow
# 📋 Dashboard de Controle de Tarefas

Um dashboard simples e funcional para gerenciamento de tarefas do dia a dia, desenvolvido com **HTML, CSS e JavaScript puro**. Ideal para organizar atividades de forma prática e intuitiva.

---

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas  
- ✔️ Marcar tarefas como concluídas  
- ❌ Remover tarefas  
- 💾 Salvamento automático com **LocalStorage**  
- 🔢 Contador de tarefas pendentes  
- 🔍 Filtro de tarefas:
  - Todas  
  - Pendentes  
  - Concluídas  

---

## 🎨 Layout

- Interface simples, moderna e responsiva  
- Design com cores suaves e agradáveis  
- Feedback visual para tarefas concluídas  
- Botões com efeitos ao passar o mouse  

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
